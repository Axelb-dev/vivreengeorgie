# Vivre en Géorgie

Static cinematic website, deployed through GitHub Pages from main.

Production: index.html, atelier.css/js/i18n, legal page/styles, assets, images/batumi-real.png, CNAME, robots.txt, sitemap.xml and llms.txt. Desktop and mobile each have their own frame sequence and aligned detailed stills.

Run tests/preview_server.py with Python for a local preview. Tests require Python + BeautifulSoup and Node + Playwright/installed Edge; adjust the local Playwright module path in browser checks for another machine. Internal tests/review files are excluded by _config.yml.

Retired designs, original test videos and generation prompts are archived outside this repository under ../archives-refonte. They are not required for runtime.

Legal information still missing from the editor is recorded in LEGAL_INFORMATION_REQUIRED.md. Do not invent these fields.
